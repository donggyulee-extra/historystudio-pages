Who uses this app

HistoryStudio Upload is used only by its owner to manage the owner's own YouTube channels and Instagram accounts. It is not offered to other users.

Google user data we access

With the owner's permission (Google sign-in), the app uses these YouTube Data API scopes: youtube.upload (upload videos to the owner's channel) and youtube.force-ssl (set thumbnails, add videos to playlists, upload caption files, and read the owner's own video status). It does not read, collect or use any data about other people.

How the data is used, stored and shared

  • Used only to upload and manage videos the owner has approved, on the owner's own channels.
  • Sign-in tokens are stored only in a local file on the owner's computer. Nothing is sent to any server other than Google's and Meta's official APIs.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • HistoryStudio Upload's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions and delete the local token file. YouTube's terms apply to uploaded content: YouTube Terms of Service, and Google's privacy policy: policies.google.com/privacy.
